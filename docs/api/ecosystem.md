# Ecosystem API

These adapters have separate runtime and dependency contracts. API-reference
generation and optional dependency installation do not establish stability.
The [DRF guide](../drf.md) describes the verified serializer/ORM behavior and its
boundaries. The [current plan](../status.md) still requires a GraphQL API
stability decision before expanding GraphQL runtime integration.
